
Student Grade Calculator

Project Description

Student Grade Calculator is a simple Java console-based application. It accepts a student's marks in five subjects and calculates the total marks, percentage, and grade.

Features

- Accepts the student's name
- Accepts marks in five subjects
- Calculates total marks
- Calculates percentage
- Displays the grade

Technologies Used

- Java
- Scanner class
- For loop
- Conditional statements

Requirements

- Java Development Kit (JDK) 8 or above
- Command Prompt, Terminal, or any Java IDE

How to Set Up and Run

Step 1: Install Java

Install JDK 8 or a newer version.

Check the installation using:

java -version
javac -version

Step 2: Download the Repository

Download this repository as a ZIP file and extract it.

Step 3: Open the Project Folder

Open the folder containing "StudentGradeCalculator.java".

Step 4: Compile the Program

Open Command Prompt or Terminal in the project folder and run:

javac StudentGradeCalculator.java

Step 5: Run the Program

Run:

java StudentGradeCalculator

Step 6: Enter Details

Enter the student's name and marks for five subjects. The program will display the total, percentage, and grade.
